# НОВОГРАД: план улучшений

Статус на 14.08.2026: версия 1.0.1 в бете на `/next/`, все механики полной
игры работают (три стартовых актива, такси, е-ком, Plus, партнёрства,
третий акт, мета-слой). План собран из замеров баланса, известных слабых
мест и накопленных отзывов. Порядок внутри блоков — по убыванию отдачи.

Правила, которые план не отменяет: модели старых игр не трогаем (только
аддитивные крючки), обратные бонусы строго неэкономические, баланс — только
замерами по методологии HANDOFF, серверный скрипт обновляет автор руками.

## Блок 1. Выход из беты (критерии для вливания в корень сайта)

Цель: `/next/` становится основной версией, старые ссылки получают четвёртую
игру. Это решение принимает автор; блок — чек-лист готовности к нему.

1. **Тег «НОВОГРАД» на сервере таблицы.** Ручной шаг автора: заменить
   `server/leaderboard.gs` в Apps Script (файл уже прислан) и передеплоить.
   Без этого отправка рекордов отвечает «unknown game».
2. **Выровнять ощущение от старта за билеты.** Замер: доведённые стратегии
   дают доставка 12.9 / стриминг 13.0 / билеты 2.3 млрд. Это осознанный
   «сложный режим», но шкала вердиктов одна на всех — финал за билеты
   почти всегда читается как «скромный итог», хотя партия сыграна хорошо.
   Решение без правки экономики: шкала вердиктов и реплики совета берутся
   из дескриптора актива (у билетов свои пороги). Критерий: хорошая партия
   за любой актив получает высокий вердикт; лидерборд при этом общий —
   в строке результата актив уже виден по коду партии.
3. **Пройти игру на реальном телефоне** (Safari + Chrome): карта, развилки
   месяца 0, финальный экран, ввод строки наследия. После правки карты
   автопроверки чистые, но живого прогона на устройстве не было.
4. **Английские доки экосистемы.** `docs/ecosystem/en/economics.md` и
   `en/teacher-guide.md` — сейчас английский README ссылается на русские
   тексты, это единственная игра без EN-доков.
5. **Вычитка второго прохода.** Свежим взглядом после недели паузы: тексты
   событий и советы (`events.js`), реплики совета, справка. Первый проход
   снял главное (хаб ≠ «еда»), но события писались до переименований.

## Блок 2. Геймплей: меньше ровных месяцев (1.1)

Замеры показывают, что решения сосредоточены в месяцах 1–12 (запуски,
война) и 30–36 (третий акт, рывок). Середина партии — «жми дальше».
Агентность в месяцах 14–26 держится на событиях, а их пул конечен.

1. **Кризис середины партии — сделано (1.2).** Антимонопольное дело о
   связывании сервисов: приходит принудительно к 22-му месяцу, три исхода
   расходятся навсегда (логистика / подписка / суд и надзор), аудит на
   полной сборке 13/75/13 при дешёвом капитале и 40/20/40 при дорогом.
   Исходная формулировка задачи: одна гарантированная сюжетная развилка в
   месяцах 16–22 с последствиями до конца партии (по образцу
   `fed_ecosystem`, но с выбором стратегии, а не только «платить/терпеть»).
   Кандидаты: регулятор требует разделения логистики; профсоюз водителей;
   якорный партнёр хаба уходит к федералам. Критерий: аудит доминирования
   даёт живой выбор (ни одна опция не берётся в 100% прогонов при
   дефиците капитала), сдвиг счёта между ветками ощутим (3–8%).
2. **Четвёртая вертикаль как проверка архитектуры.** Самокаты лежат в
   `FUTURE_VERTICALS` заглушкой — довести до играбельной: сезонность,
   короткая поездка, парк как капитал. Ценность двойная: контент и
   доказательство, что вертикаль подключается данными без правки движка.
   Гейт: год 2+, работающее такси (общая мобильность). Обязательный
   полный цикл замеров: тайминг запуска — решение, «никогда» — тоже.
3. **Пост-эндгейм.** «Бесконечный режим» сейчас голый (`enterEndless`).
   Минимальный осмысленный вариант: после месяца 36 совет ставит одну
   большую цель на 12 месяцев (например, прибыльная экосистема при
   двукратной базе), счёт партии заморожен (уже так), отдельная строка
   результата с пометкой NG+. В лидерборд NG+ не идёт, пока автор не
   решит иначе (правило сервера — ручное).
4. **События: расширение пула.** Сейчас 14 + штраф; к месяцу 30 при
   p=0.45 пул заметно вычерпывается. Добавить 6–8 событий с упором на
   е-ком и Plus (у них почти нет своих событий: сбой фулфилмента в пик,
   демпинг маркетплейса, партнёр Plus поднимает цену лицензии).
   Каждое — через аудит доминирования.

## Блок 3. Обучающая ценность (1.1–1.2)

1. **Контрфактический разбор решений.** В старых играх есть «сколько
   принёс алгоритм на самом деле»; в НОВОГРАДЕ аналога нет. Кандидат:
   вкладка «Разбор» в финале — прогнать эту же партию с «никогда не
   запускать такси» / «без Plus» / «без кросс-селла» и показать разницу
   оценок. Движок чистый и детерминированный — это три вызова симуляции.
   Это прямой ответ на вопрос финала «что было бы, если бы вы просто
   дожимали еду», который сейчас задаётся риторически.
2. **Объяснение суммы частей по строкам.** В таблице оценки дать каждой
   строке «почему»: из чего сложился множитель (рост, маржа, зоопарк).
   Формула уже считается по компонентам — вывести её в подсказку строки.
3. **Сценарии занятий: сравнительная партия.** В teacher-guide добавить
   сценарий «три группы — три актива, один код партии»: одинаковый город,
   разные экосистемы; обсуждение, почему формы разошлись.

## Блок 4. UX-долг (по мере)

1. Тач-цели «зачем это?» меньше 28px на десктопе (на телефоне уже
   расширены псевдоэлементом) — унифицировать.
2. Приветствие на телефоне длинное: четыре абзаца до выбора актива.
   Свернуть вводные в раскрывашку, выбор актива поднять выше.
3. Подсветка «карта кликабельна»: узлы ведут к рычагам и панелям, но
   ничто об этом не говорит. Лёгкий hint при первом открытии.
4. Кнопки сегментов политик на 360px: не ужимаются (уже исправлено),
   но при переносе строк ряд выглядит рвано — выровнять сеткой 2×2 на
   узких экранах.

## Блок 5. Инфраструктура и процесс

1. **Автообновление `/next/`.** Сейчас после пуша в ветку НОВОГРАДА
   workflow надо перезапускать вручную (окружение github-pages пускает
   деплой только с ветки сайта). Если добавить ветку НОВОГРАДА в
   разрешённые (Settings → Environments → github-pages → Deployment
   branches) — ручной шаг автора, — можно вернуть пуш-триггер, и `/next/`
   будет обновляться сам. До тех пор перезапуск остаётся на мне.
2. **Playwright-смоук в CI.** Полный браузерный прогон живёт локально в
   скриптах сессии; перенести минимальный смоук (загрузка, 3 хода, финал
   через форс) в workflow перед деплоем. Стоимость ~1 мин на прогон.
3. **Замеры как артефакт репозитория.** Скрипты harness/slices/anchors
   лежат в scratchpad сессии; перенести в `games/ecosystem/tools/` с
   README, чтобы перебалансировка была воспроизводима без меня.
4. **Метрика воронки.** На сайте уже есть Яндекс.Метрика; добавить цели:
   старт партии, выбор актива, месяц 12, финал, отправка рекорда. Даст
   ответ, где игроки бросают, — прицел для блока 2.

## Блок 6. Дальше (2.0, по желанию)

- Пятая исходная игра (по плану серии) → новый стартовый актив по
  контракту дескриптора; НОВОГРАД правок не требует — это и есть тест
  архитектуры.
- Конкурирующая экосистема как живой агент (сейчас федералы — событие):
  отдельный «игрок» с бюджетом и политикой, по образцу конкурента
  КИНОРЕКИ. Самая дорогая идея плана — только после того, как метрика
  покажет, что игроки доигрывают до третьего акта.
- Режим «совет директоров»: игрок задаёт годовые цели сам себе перед
  партией (контракт), счёт умножается на их амбициозность. Дешёвая
  реиграбельность поверх готового движка.
