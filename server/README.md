# Сервер мировой таблицы результатов

Игры умеют показывать глобальную таблицу и отправлять в неё результаты, но
сервер для этого нужно развернуть один раз вручную — бесплатно, на Google
Apps Script поверх обычной Google Таблицы. Занимает 5 минут.

## Развёртывание

1. Создайте новую [Google Таблицу](https://sheets.new) (например,
   «Симуляторы — рекорды»). Записи будут копиться на листе `scores`.
2. В меню таблицы: **Расширения → Apps Script**. Удалите заглушку и вставьте
   целиком содержимое файла `server/leaderboard.gs`. Сохраните.
   Рекомендуется сразу сузить доступ скрипта до одной таблицы: в настройках
   проекта (шестерёнка) включите «Показывать файл манифеста appsscript.json»
   и замените его содержимое на `server/appsscript.json` — scope
   `spreadsheets.currentonly` даёт скрипту доступ только к той таблице,
   из которой он создан, а не ко всем таблицам аккаунта.
3. **Развернуть → Новое развёртывание → Тип: Веб-приложение**:
   * «Выполнять от имени» — **от моего имени**;
   * «У кого есть доступ» — **у всех**.
   Нажмите «Развернуть» и скопируйте URL вида
   `https://script.google.com/macros/s/…/exec`.
4. Впишите этот URL в три файла `games/*/index.html` — в блоке
   `only-modular` есть строка:

   ```js
   window.__lbEndpoint = null;
   ```

   Замените `null` на `'https://script.google.com/macros/s/…/exec'`
   и запушьте: сайт пересоберётся сам.

Офлайн-файлы (`dist/*.html`) адреса сервера не содержат: в классе без
интернета таблица просто не показывается, и игра ничего никуда не шлёт.

## Что проверяет сервер

* Контрольную сумму строки результата (тот же djb2-xor, что печатает игра);
  счёт, код партии и ходы разбираются из строки — присланные отдельно числа
  сервер не читает.
* Название игры — только НОВОЕДА / КИНОПОТОК / БИЛЕТОН.
* Имя — до 24 символов; та же строка от того же имени второй раз
  не записывается.

## Обновление скрипта

Правки в `server/leaderboard.gs` нужно перенести в редактор Apps Script и
сделать **Развернуть → Управление развёртываниями → карандаш → Новая версия**.
URL при этом не меняется.

## Модерация

Все записи лежат в обычной таблице — строку с неприличным именем можно
просто удалить, таблица этого не заметит. Резервная копия — «Файл → Скачать».
