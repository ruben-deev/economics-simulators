Страница открыта из папки

Браузер не загружает модули с диска — это ограничение безопасности, одинаковое в Safari и в Chrome. Открыть игру можно двумя способами:

1. Открыть dist/novoeda-delivery-simulator.html — та же игра одним файлом, она работает прямо из папки.
2. Запустить локальный сервер: npm start в корне проекта.
