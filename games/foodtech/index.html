Скрипты не выполняются

Игра — это расчётная модель, она целиком живёт в JavaScript. Сейчас он выключен, поэтому виден только пустой каркас.

Чаще всего так бывает при предпросмотре файла: на айфоне — когда файл открыт из «Файлов», почты или мессенджера с кнопкой «Готово», на маке — в «Быстром просмотре» с кнопкой «Открыть в приложении Safari». Предпросмотр намеренно не запускает скрипты.

Что делать: открыть файл в самом браузере. На маке — «Открыть в приложении Safari» вверху окна, либо перетащить файл на иконку браузера. На айфоне — «Поделиться» → «Открыть в Safari»; если такого пункта нет, откройте игру по ссылке в браузере — на телефоне это надёжнее, чем файл.

Страница открыта из папки

Браузер не загружает модули с диска — это ограничение безопасности, одинаковое в Safari и в Chrome. Открыть игру можно двумя способами:

1. Открыть dist/novoeda-delivery-simulator.html — та же игра одним файлом, она работает прямо из папки.
2. Запустить локальный сервер: npm start в корне проекта.
